# 260903_ricehack

「精米したてのご飯がある暮らし」をテーマに、玄米の保管・自宅精米・5分づき・黒米・冷凍保存・活力鍋での炊飯・米ぬかの循環までをまとめた個人向け実用ガイドです。

## 主な内容

- 自宅精米のメリットとコイン精米との比較
- 山本電気 MB-RC52 と i-rice の比較
- 5分づきの実運用
- 米ぬか処理・精米機のお手入れ
- 黒米 10g/合、冷凍ごはん 150g/食
- ライスエース33kg、米唐番、米洗いザル、TANITA KJ-304
- ゼロ活力なべ Lスリム + Rinnai Lisse の炊飯手順
- 実測データを使った水量計算機
- Reencle を使う生活循環案
